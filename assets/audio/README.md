# ScreenBot ambient audio assets

The eight short Ogg Vorbis loops in this directory were created specifically for ScreenBot using the reproducible synthesis recipe in [`tools/generate_ambient_audio.py`](../../tools/generate_ambient_audio.py). They use locally generated filtered noise, oscillators, and envelopes; no third-party recordings or samples are incorporated. The original generated recordings and their Vorbis encodings are dedicated to the public domain under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/), as declared in [`LICENSE.txt`](LICENSE.txt).

Continuous loops are mono, 22.05 kHz, and eight seconds long; `thunder.ogg` is a two-second one-shot. `rain.ogg` covers rain, `thunder.ogg` plays 1.1 seconds after the same deterministic lightning event rendered on screen, `wind.ogg` covers snow and fog, `forest.ogg` and `crickets.ogg` cover Forest by day and night, `waves.ogg` cover Ocean and Underwater, `city.ogg` covers Futuristic City, and `space.ogg` provides a quiet synthetic hum. Thunder temporarily uses the existing player stream, then rain resumes when the one-shot ends. Live Sky rain intensity scales gain below the user's selected volume limit. Ambient audio is off by default.
