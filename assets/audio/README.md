# ScreenBot ambient audio assets

The nine compact Ogg Vorbis ambience files in this directory were created specifically for ScreenBot using the reproducible synthesis recipe in [`tools/generate_ambient_audio.py`](../../tools/generate_ambient_audio.py). They use locally generated filtered noise, oscillators, and envelopes; no third-party recordings or samples are incorporated. The original generated recordings and their Vorbis encodings are dedicated to the public domain under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/), as declared in [`LICENSE.txt`](LICENSE.txt).

Continuous loops are mono, 22.05 kHz, and eight seconds long; `thunder.ogg` is a two-second rain-and-rumble one-shot, and `owl.ogg` is a three-second cricket-and-owl one-shot. `rain.ogg` covers rain, `thunder.ogg` plays 1.1 seconds after the same deterministic lightning event rendered on screen, `wind.ogg` covers snow and fog, `forest.ogg` and `crickets.ogg` cover Forest by day and night; occasional owl cues play over crickets using `owl.ogg` (first eligible at 35 seconds, then every 73 seconds while Forest is at night), `waves.ogg` covers Ocean and Underwater, `city.ogg` covers Futuristic City, and `space.ogg` provides a quiet synthetic hum. The thunder cue carries rain beneath its delayed rumble, temporarily uses the existing player stream, then the continuous rain loop resumes. The owl cue similarly carries cricket ambience beneath two synthesized hoots and returns to the cricket loop afterward. Live Sky rain intensity scales gain below the user's selected volume limit. Ambient audio is off by default.
